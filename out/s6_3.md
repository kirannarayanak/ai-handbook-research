### Coding and engineering assistants

These six tools span IDE assistants (GitHub Copilot, Gemini Code Assist, Amazon Q Developer), an AI-native editor (Cursor), a terminal/cloud coding agent (Claude Code) and the open-source test framework (Playwright) that all of them now drive through MCP servers and agent definitions. They compete head-on in agentic multi-file coding, automated PR review and enterprise controls, and increasingly resell the same frontier models: Copilot and Cursor offer Claude, GPT and Gemini, while Claude Code itself runs inside VS Code and Cursor and on Bedrock, Google Cloud Agent Platform and Microsoft Foundry. 2026 was a consolidation year: Google stopped selling new Code Assist subscriptions (Oct 9) in favour of Antigravity, AWS announced Q Developer's end of support for Kiro (Apr 30 2027), SpaceX folded Cursor into a Grok/X bundle (Oct 12), and GitHub moved to usage-metered AI Credits (June 1). Enterprises typically standardise on GitHub Copilot where GitHub is already the SCM, add Claude Code or Cursor for agentic work, keep the hyperscaler assistant matching their primary cloud, and adopt Playwright with its MCP server as the neutral QA layer. Procurement now has to track usage-based metering and model-provider retention terms as closely as seat prices.

*Fact-check:* Core pricing, tier and sunset claims for all six tools were re-checked against opened vendor pages and mostly held (Claude, Copilot credits, Cursor X Subscription tiers, Q/Kiro pricing, Gemini sunset dates). Weaker areas were fine-grained security attestations, changelog-level feature claims and secondary-source details, which could not be confirmed and were removed or marked not verified. Several cited pages could not be opened (github.com plans 403, Playwright v1.64.0 release 403, TechInformed) and were dropped from sources, as were cited pages not re-opened. Overall the group is reliable on prices and product status but should not be used for compliance certifications without checking each vendor's trust center. 10 correction(s) or removal(s) were applied.

**Claude Code** (Anthropic (Claude product family); high confidence)

- **Vendor and product family:** Anthropic (Claude product family). Bundled in Claude Pro, Max, Team and Enterprise; also pay-as-you-go via Anthropic Console, Amazon Bedrock, Google Cloud Agent Platform (renamed from Vertex AI) and Microsoft Foundry.
- **What it is:** Agentic coding tool that reads a codebase, edits files, runs commands and opens pull requests. Surfaces: terminal CLI, VS Code and JetBrains extensions, desktop app, web (claude.ai/code) and mobile, plus Slack, GitHub Actions/GitLab CI and an Agent SDK.
- **Key capabilities:** Multi-file edits under permission modes: auto (a classifier screens actions), manual, sandboxed bash; Subagents, dynamic workflows and a Projects coordinator for long-running parallel work; CLAUDE.md memory, skills, hooks, plugins and MCP connectors; GitHub Code Review (GA Oct 2026) with Quick/Standard/Deep levels; Scheduled routines, Remote Control, cloud sessions and CLI piping for CI and log triage
- **Enterprise data handling:** Team, Enterprise, API and cloud-provider deployments: Anthropic does not train on code or prompts unless the org opts into the Development Partner Program (first-party API only); 30-day standard retention; zero data retention is available to qualified accounts on Claude for Enterprise, enabled per organization by the account team (not included in the standard plan). Free/Pro/Max: training only if the user enables it (5-year retention on, 30 days off). Enterprise adds SSO, SCIM, RBAC, audit logs, compliance API, custom retention and a HIPAA-ready offering (per the pricing page); managed settings enforce policy. IP allowlisting, CMEK, US-only inference, BAA terms, and the SOC 2 Type 2 / ISO 27001 reports on the Trust Center were not verified in this check.
- **Licensing and pricing:** USD: Pro $20/month ($17 annual); Max from $100 (5x) up to $200 (20x)/month; Team (2 to 150 seats) Standard seat $25/month or $20 annual, Premium seat $125/$100; Enterprise $20/seat/month billed annually (20-seat self-serve minimum; 50-seat minimum sales-assisted) plus all usage at API rates. Not bundled with any office suite.
- **Integrations:** Git, GitHub, GitLab, GitHub Actions, GitLab CI/CD, Slack, Chrome debugging, OpenTelemetry, MCP servers (Jira, Google Drive, Datadog, PagerDuty, Zapier, Workato, Notion, Asana), LLM gateways. Specific MCP server list not re-verified.
- **2025-2026 developments:** May 2026 Code with Claude: auto-mode classifier, worktrees, routines, remote control. Sept 17 2026: Claude Code Projects launched. Oct 2026: Code Review GA for Team and Enterprise, with eligible Enterprise orgs able to claim at least $10,000 in Code Review credits by Jan 15 2027. Vertex AI is now Google Cloud Agent Platform. The v2.1.310 / Oct 23 changelog items were not re-verified.
- **Best-fit handbook departments:** Strong: 41, 42 (test generation with the Playwright agent loop), 44 (log piping, MCP runbooks), 49 and 51 (Agent SDK, workflows). 43 fits for IaC but lacks the native cloud cost analysis Amazon Q or Azure Copilot provide.
- **Training notes:** Master permission modes and auto-mode risk, CLAUDE.md, plan-then-execute, diff review, MCP trust, sandboxing and usage monitoring. Core 8-10 h (41); Advanced 14-18 h (42, 44); Specialist 24-32 h (43, 49, 51: Agent SDK, Bedrock/Foundry deployment, OpenTelemetry).

**Playwright** (Microsoft (open source, Apache-2.0, github.com/microsoft/playwright); medium confidence)

- **Vendor and product family:** Microsoft (open source, Apache-2.0, github.com/microsoft/playwright). Not an AI SaaS; AI arrives through Playwright Test Agents, the Playwright MCP server and the optional Azure App Testing service (formerly Microsoft Playwright Testing).
- **What it is:** Browser automation and end-to-end test framework for Chromium, Firefox and WebKit in TypeScript/JavaScript, Python, .NET and Java, with a test runner, codegen and trace viewer. Ships agent definitions (Planner, Generator, Healer; introduced Oct 2025) and an MCP server that let coding assistants plan, write and heal tests.
- **Key capabilities:** Auto-wait, retrying assertions, role-based locators, parallel sharding, isolated contexts; Test Agents Planner, Generator and Healer; Playwright MCP drives browsers through accessibility snapshots; Trace viewer, video recording; v1.64: WebMCP testing, --shuffle, test locks, project default option
- **Enterprise data handling:** The framework runs locally; no data goes to Microsoft. Agent and MCP traffic goes to whichever LLM client the team uses, so that vendor's policies govern code exposure. Azure Playwright Testing stores reports for 90 days in the workspace region (East US, West US 3, East Asia, West Europe); Azure attestations were not verified.
- **Licensing and pricing:** Free, Apache-2.0. Azure App Testing is consumption-based; per-minute rates not verified. LLM costs sit with the chosen assistant.
- **Integrations:** VS Code, Claude Code, Codex, OpenCode, Cursor and GitHub Copilot via MCP (client list not individually verified); Leapwork commercial orchestration layer.
- **2025-2026 developments:** Playwright release notes list v1.64 with WebMCP, video fps/style options, --shuffle and test locks. The v1.64.0 GitHub release page could not be opened (403), so its date and other version-by-version items (v1.56-v1.63) and star counts are not verified.
- **Best-fit handbook departments:** 42 Quality Engineering is the core fit for automation scripts and defect triage; also useful to 41 for component tests.
- **Training notes:** Locators, fixtures, trace viewer, CI sharding and flaky-test triage, then agent loops and reviewing generated specs. Advanced 12-20 h (42); Specialist 20-30 h for framework owners running agents and MCP in CI.
- **Caveats:** Agents need human review; Healer can mask real regressions. Enterprise orchestration, scheduling and audit sit outside the framework. Release date of v1.64 not verified.
