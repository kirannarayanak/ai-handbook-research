### Data, analytics and AI development platforms

These seven tools sit at different layers of the data and AI stack. Databricks Genie Code and Snowflake CoCo/Cortex are AI assistants and AI functions embedded in the two leading data platforms, serving data engineering and analytics inside their own governance models. Tableau Pulse is a business-user metrics and insights layer, and competes with Power BI Copilot elsewhere in the handbook. Google AI Studio, Microsoft Foundry (formerly Azure AI Foundry) and Amazon Bedrock are hyperscaler model and agent platforms for building RAG and agent applications, and each competes for the same workloads. MLflow is the vendor-neutral open-source layer for tracing, evaluation and registries that can sit across the others, and is also bundled into Databricks. Enterprises usually standardise on the data platform they already run (Databricks or Snowflake) and the cloud AI platform that matches their hyperscaler contract. They use Google AI Studio only for prototyping, and move production work to the governed cloud tier.

*Fact-check:* Core vendor-page claims were confirmed on opened pages: Databricks trust and billing, Snowflake AI Credit prices, Tableau Pulse release items and trial terms, Google's no-certification statement, Foundry data privacy and free platform, Bedrock tiers and compliance scope, and MLflow 3.17 and Apache 2.0. Many secondary claims (Snowflake renames and blog-derived data handling, Tableau seat prices, Google pricing, Foundry and Bedrock integrations) had no opened support and were removed or marked not verified. Sources that were not opened were dropped from the lists. Pricing pages for Tableau and Google remain unchecked, so those tools carry lower confidence. 9 correction(s) or removal(s) were applied.

**Databricks Assistant** (Databricks; medium confidence)

- **Vendor and product family:** Databricks. Now marketed as Genie Code, part of the Databricks Genie family. The brief's name is out of date.
- **What it is:** Databricks Assistant was renamed Genie Code in March 2026 and became an autonomous agent for data teams. It runs inside the Databricks workspace (notebooks, SQL editor, Lakeflow Pipelines Editor, AI/BI dashboards, MLflow). It plans multi-step tasks, writes and runs code, and fixes errors, within the user's Unity Catalog permissions.
- **Key capabilities:** Generates, runs and debugs SQL and Python in notebooks and the SQL editor; Builds and maintains Lakeflow/Spark Declarative Pipelines and monitors them for failures; Creates AI/BI dashboards and exploratory analyses from natural language; Agent plans for review before execution, custom instructions, agent skills and MCP connections; Scheduled tasks (Beta) and an agentic converter (Beta) for legacy SQL dialects
- **Enterprise data handling:** Per Databricks' trust page (the claim that it applies to all tiers is not verified). Databricks does not use prompts, data or responses to train generative foundation models offered to third parties. Partner model providers (Azure OpenAI, OpenAI on Databricks, Anthropic on Databricks) use zero data retention endpoints. All data sent respects Unity Catalog permissions. Traffic uses TLS and workspace data is AES-256 encrypted; customer-managed keys are not verified here. Genie Code is a Designated Service that follows Geo data residency; in-country routing was added in March 2026 for Brazil, Canada, Japan, Korea, Singapore and the UK. The trust page has a section on PHI, PCI, IRAP and FedRAMP data; the compliance security profile requirement is not verified in detail. From July 2026, HIPAA-profile workspaces can use it only with partner-powered AI disabled, so the Databricks-hosted model serves it. By default an AI classifier auto-approves the agent's actions; users can switch to manual approval.
- **Licensing and pricing:** No per-seat list price was found. Since 8 July 2026 Genie Code is pay-as-you-go with a per-user monthly free allowance, managed through account budgets. The size of the allowance is not verified. Genie One and Genie Agents are free for users through 31 January 2027 (service principals excluded and billed). It is not bundled with a suite; it requires a Databricks workspace.
- **Integrations:** Unity Catalog, Lakeflow, AI/BI dashboards and MLflow. MCP connections are supported; the specific Jira, Confluence and GitHub connectors are not verified. Relevant to dept 49 Data Engineering.
- **2025-2026 developments:** RENAME: Databricks Assistant is now Genie Code (March 2026), with agentic capabilities. Pay-as-you-go billing began 8 July 2026. HIPAA-profile support (partner AI off) and scheduled tasks (Beta) arrived in July 2026. In-country AI routing was added in March 2026.
- **Best-fit handbook departments:** 49 Data Engineering & Data Platforms is a strong fit for SQL generation, pipelines and quality troubleshooting, but only for organisations on Databricks.
- **Training notes:** Learners need Unity Catalog permissions, prompt and plan review, approval modes, and testing of generated code before production. Suggested 24-32 hours (Specialist band).
- **Caveats:** Agentic features need partner-powered AI enabled and a supported region. Auto-approve mode can execute code, so choose approval mode deliberately. Databricks warns that output can be wrong. Usage is metered, so cost controls matter.
- **Sources (4):** [Genie Code (Databricks docs)](https://docs.databricks.com/aws/en/genie-code/) · [Databricks AI assistive features trust and safety](https://docs.databricks.com/aws/en/databricks-ai/databricks-ai-trust) · [Databricks release notes March 2026](https://docs.databricks.com/gcp/en/release-notes/product/2026/march) · [Databricks release notes July 2026](https://docs.databricks.com/aws/en/release-notes/product/2026/july)

- **Best-fit handbook departments:** 49 Data Engineering & Data Platforms is a strong fit for SQL-native AI, document extraction and quality checks, but only for Snowflake estates.

**Tableau Pulse** (Salesforce (Tableau); medium confidence)

Prompt and response audit data is stored in Salesforce Data 360 and not shared with the LLM provider. The GPT-5.2 model draws on precomputed insights and does not analyse the raw data itself. Site-level enablement is confirmed; compliance attestations were not verified.
- **Licensing and pricing:** Not verified. The per-seat figures from a third-party summary were removed because that page was not opened. Tableau Agent in Pulse requires a Tableau+ license edition after the 60-day Try AI trial (contact sales); insight summaries and semantic matching do not need Tableau+. **MLflow** (Open source project (Linux Foundation affiliation not verified), or...; high confidence)

- **Vendor and product family:** Open source project (Linux Foundation affiliation not verified), originally created by Databricks. Managed versions are offered by Databricks and cloud providers.
- **What it is:** MLflow is an open-source AI engineering platform for agents, LLM applications and classic ML models. You self-host it or use a managed version (for example MLflow on Databricks). It provides a server, UI and SDKs.
- **Key capabilities:** Tracing and observability for agents and LLM apps; Evaluation with LLM-as-a-judge scorers and datasets; Prompt management and optimisation; AI Gateway for model access; Experiment tracking, model registry and deployment
- **Enterprise data handling:** Not applicable as a vendor service when self-hosted: data stays in the organisation's own infrastructure, and security depends on the deployment. Role-based access control arrived in MLflow 3.13 and was extended in 3.17 (October 2026) to runs, traces, assessments, logged models, review queues and model, prompt, scorer and MCP-server versions, with a DENY permission. The managed version on Databricks falls under Databricks' platform terms, and no SOC 2, ISO 27001, HIPAA or FedRAMP claim was verified for MLflow itself.
- **Licensing and pricing:** Free and open source under Apache 2.0, per mlflow.org. Costs are infrastructure and staff, or Databricks usage if managed.
- **Integrations:** Any LLM provider, agent framework and ML library (per mlflow.org general positioning; specific integrations not itemised). Relevant to dept 51.
- **2025-2026 developments:** MLflow 3.17.0 (6 October 2026) added extended resource permissions (RBAC with DENY), TypeSafe Jev judge models and faster trace analytics. The project reports over 30 million monthly downloads. RBAC with an Admin UI first shipped in 3.13.
- **Best-fit handbook departments:** 51 AI, Machine Learning & Automation is the only listed department and the fit is strong for evaluation, tracing and MLOps governance.
- **Training notes:** Learners need experiment and trace logging, designing evaluation datasets and judges, registry versioning, and access control. Suggested 20-30 hours.
- **Caveats:** Self-hosting needs operations effort. Features move quickly between releases. LLM-as-a-judge scores need human calibration.
- **Sources (2):** [MLflow](https://mlflow.org/) · [MLflow releases (3.17.0)](https://mlflow.org/releases)
