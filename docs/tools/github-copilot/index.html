What it is

AI pair programmer and coding agent inside VS Code, Visual Studio, JetBrains, Neovim, Eclipse and Xcode, on GitHub.com, GitHub CLI, GitHub Mobile and Windows Terminal. Multi-model: OpenAI, Anthropic, Google and xAI models are selectable per task.

Vendor and product family
GitHub (Microsoft subsidiary). Copilot family: Free, Pro, Pro+, Max for individuals; Business and Enterprise for organisations.
Handbook category
Coding & engineering

Key capabilities

  • Completions and Next Edit Suggestions (not credit-metered) plus agent mode in the IDE
  • Cloud coding agent that turns issues into pull requests; Copilot code review
  • Copilot Spaces for shared context; custom agents, instructions and MCP servers with allow lists
  • Agentic autofix for code-scanning alerts; local sandboxing; computer use for desktop apps (changelog items not re-verified)
  • Usage metrics API covering custom skills, agents and MCP servers (not re-verified)

Enterprise data handling

GitHub Terms (effective Apr 27 2026): the clause letting GitHub train on inputs and outputs applies only to individual licences (opt-out in account settings); use under a GitHub Customer Agreement or volume licence is governed by those agreements. GitHub holds zero-data-retention agreements with OpenAI and Anthropic (GA features); Claude Fable 5/5.1 are not covered by default (Anthropic retains data for safety classifiers; eligible enterprises can request ZDR through end of 2026). Admin policy, content exclusions, audit logs and MCP allow lists, and the Trust Center attestations, were not verified here.

Licensing and pricing

USD monthly: Free $0; Pro $10 (1,500 AI Credits); Pro+ $39 (7,000); Max $100 (20,000); Business $19 per granted seat (1,900 credits); Enterprise $39 per seat (3,900). Since June 1 2026 usage is metered in GitHub AI Credits at $0.01 each beyond pooled allowances; completions and next edit suggestions stay unmetered on paid plans. Microsoft Product Terms purchasing and 365 non-bundling not verified.

Integrations

GitHub repositories, issues, pull requests and Actions; MCP servers; Visual Studio, VS Code and JetBrains; multi-vendor model catalogue. Teams notifications not verified.

2025-2026 developments

AI Credits replaced premium requests on June 1 2026 (Directions on Microsoft). Business/Enterprise promotional credit amounts and the Oct 2026 changelog items (Gemini 4 Argon, Claude Haiku 5.5, model deprecation dates) were not verified.

Best-fit handbook departments

Strong: 41, 42, 53 (Spaces for ADRs, org-wide indexing) and 52 prototyping. Moderate: 43, 44, 49 - no cloud-specific troubleshooting or cost tooling; relies on MCP connectors to observability and data platforms.

Listed for these departments in the handbook

41 Software Engineering - Applications42 Quality Engineering & Testing43 Cloud Infrastructure & Platform Engineering44 DevOps & Site Reliability Engineering49 Data Engineering & Data Platforms52 Research, Innovation & Emerging Technology53 Enterprise Architecture & Integration

Training notes

Learn instruction files, agent mode versus cloud agent, reviewing agent PRs, credit budgeting and model choice. Core 6-8 h (41); Advanced 12-16 h (42, 52); Specialist 20-24 h (43, 44, 49, 53: policy admin, metrics API, MCP governance).

Caveats

Token-based credits make spend hard to predict; admins must set limits. Frequent model deprecations. Fable retention nuance. Individual tiers allow training unless opted out. github.com plans page and Trust Center could not be opened (403/script-rendered), so certifications and retention figures are not verified.
