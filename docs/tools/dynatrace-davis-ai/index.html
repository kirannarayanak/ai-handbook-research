What it is

What the tool is and where it lives, in plain language.

The AI layer of the Dynatrace observability platform. It combines deterministic causal AI with agentic and generative AI to detect problems, find root cause, answer natural-language questions and propose or run remediation. It is used inside the Dynatrace platform, IDEs and workflows.

Vendor and product family
Dynatrace (now marketed as Dynatrace Intelligence; Davis CoPilot is described as evolving into Dynatrace Assist)
Handbook category
Security & observability

Key capabilities

The main things it can do today.

  • Causal-AI root-cause analysis using the Smartscape dependency graph and Grail data lakehouse
  • Built-in agents for SRE, development and security use cases
  • Dynatrace Assist: natural-language Q&A and query (DQL) generation
  • Code-level fix proposals and agentic workflows for Kubernetes anomalies
  • Orchestration of partner agents (specific partner list not re-verified)

Enterprise data handling

What happens to the information you type in: whether the vendor trains on it, where it is stored, how long it is kept, and which security standards it meets.

Applies to Dynatrace SaaS. Prompts go to enterprise LLM vendors, which per Dynatrace do not store data or use prompts to fine-tune models. Dynatrace says it does not use customer data to fine-tune its DQL model. EMEA environments are processed in the EU; NORAM, LATAM and APAC in the US. Storage of prompts for product understanding and PII masking details were not re-verified. The Dynatrace trust centre lists FedRAMP Moderate and SOC 2 Type II at company level (not specific to the AI features); HIPAA and ISO 27001:2022 were not re-verified.

Licensing and pricing

How it is paid for: per user, per usage, or bundled with something you already own.

Annual platform commitment with rate-card consumption, not per user (commitment model not re-verified). Pricing page confirms full-stack monitoring USD 58 per month per 8 GiB host (billed at USD 0.01 per memory-GiB-hour); infrastructure monitoring USD 29 per month. Pricing for Dynatrace Intelligence AI features specifically was not verified; contact sales.

Integrations

The other systems it connects to, and which handbook departments that matters for.

ServiceNow, AWS, Azure, Google Cloud, Atlassian, GitHub, Red Hat; VS Code and JetBrains (not re-verified). Relevant to department 44.

2025-2026 developments

What changed recently, including renames and products being retired.

Jan 2026 (Perform): Dynatrace launched Dynatrace Intelligence, an 'agentic operations system' pairing deterministic and agentic AI, with domain agents for SRE, development and security. This is a rename or evolution of Davis AI; the current AI page uses the Dynatrace Intelligence name. The company claims an external SRE agent working with its deterministic agents solved problems up to 12 times more often (vendor benchmark, per IT Brief).

What a learner must be able to do, and how many hours to budget.

Learners must master Dynatrace topology and DQL basics, interpreting causal problem cards, agent guardrails and PII handling. Suggested 20-28 hours (Specialist band).

Jargon on this page

  • AgentAn AI that does not just answer but takes actions: runs code, opens tickets, sends messages, edits systems. Agents need an approval step for anything that cannot be undone.
  • PromptThe instruction or question you give an AI tool. Clear prompts with context and a desired format get better results.
  • TierThe handbook's training depth: Core (6-10 hours per tool), Advanced (12-20), Specialist (20-40+). A department's tier sets how long to budget.
  • VerifiedVerified means a researcher opened the page and read the claim on it. Not verified means it came from a search snippet or a page that would not load, so treat it with care.
  • Vendor claimA figure published by the company that sells the tool. It may be true, but no one independent has checked it.
  • SOCSecurity Operations Centre: the team that watches for cyber attacks. SIEM is the software that collects their security logs.
  • IDEIntegrated development environment: the program developers write code in (VS Code, JetBrains). Coding assistants live inside it.
