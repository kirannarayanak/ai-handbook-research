What it is

What the tool is and where it lives, in plain language.

Managed, organisation-wide Perplexity with admin controls, SSO, shared Projects and file-connector search, plus Perplexity Computer agent access on both tiers.

Vendor and product family
Perplexity AI, Inc. Tiers: Enterprise Pro and Enterprise Max, plus Comet Enterprise browser.
Handbook category
General AI assistant

Key capabilities

The main things it can do today.

  • Perplexity Computer agent: 500 credits/month per Enterprise Pro seat, 15,000 per Enterprise Max seat (verified)
  • Governed File Connectors and shared Projects
  • Enterprise Max adds Model Council, higher Deep Research and file-creation limits, up to 1,000 file uploads/week (vs 100), Brain (research preview)
  • SCIM, audit logs, configurable retention and Insights require one Enterprise Max seat or 50 Enterprise Pro seats
  • Comet Enterprise browser features (MDM, CrowdStrike): not verified

Enterprise data handling

What happens to the information you type in: whether the vendor trains on it, where it is stored, how long it is kept, and which security standards it meets.

Enterprise data is never used to train or fine-tune Perplexity models; agreements with third-party model providers prevent training on the data. Files attached to sessions are deleted after 7 days; custom session retention needs 50+ Pro seats or one Max seat. SOC 2 Type II; Perplexity states SOC 2 Type II, HIPAA, GDPR and PCI DSS (Enterprise Max help article). ISO 27001 and FedRAMP 20x Low: not verified. Data-residency options: none found.

Licensing and pricing

How it is paid for: per user, per usage, or bundled with something you already own.

Enterprise Max: $325/seat/month or $3,250/seat/year (verified). Enterprise Pro $40/seat/month or $400/year, 25% education/nonprofit/government discount and 250-seat custom terms: not verified (vendor page lists no price; Pro and Max seats can be mixed per help articles).

The other systems it connects to, and which handbook departments that matters for.

Connectors for file sources and SSO/SCIM per help centre; the specific list (Drive, OneDrive, SharePoint, Dropbox, Box) and CrowdStrike Falcon: not verified.

Jargon on this page

  • AgentAn AI that does not just answer but takes actions: runs code, opens tickets, sends messages, edits systems. Agents need an approval step for anything that cannot be undone.
  • TierThe handbook's training depth: Core (6-10 hours per tool), Advanced (12-20), Specialist (20-40+). A department's tier sets how long to budget.
  • VerifiedVerified means a researcher opened the page and read the claim on it. Not verified means it came from a search snippet or a page that would not load, so treat it with care.
  • Data residencyWhere your data is stored and processed. Some tools keep EU or UK data in Europe; some process everything in the US. This matters for privacy law.
  • RetentionHow long a tool keeps your prompts and outputs. Enterprise plans usually let an administrator set this.
  • MCPModel Context Protocol: a standard way to connect an AI tool to other systems (files, tickets, databases). Powerful, so access should be scoped carefully.
  • SOCSecurity Operations Centre: the team that watches for cyber attacks. SIEM is the software that collects their security logs.
  • GDPRThe EU's data protection law. Any AI use involving information about identifiable people has to respect it.
