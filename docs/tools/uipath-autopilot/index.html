UiPath Autopilot

What it is

Generative-AI assistant built into UiPath: Autopilot for Developers (Studio and Studio Web), Testers, Everyone, and inside Maestro and Orchestrator. Not a standalone app.

Vendor and product family
UiPath, Inc.; Autopilot is the embedded AI assistant across the UiPath Platform for agentic automation.
Handbook category
Enterprise business platforms

Key capabilities

  • Text-to-workflow and the Autopilot coding agent (GA in Studio Desktop, Aug 2026 release notes)
  • Maestro process scaffolding from plain language
  • Testers: requirement analysis and test generation
  • Everyone: conversational assistant that runs automations and answers from documents
  • Model choice via AI Trust Layer, including Claude and GPT models (Aug 2026 release notes list Claude Opus 4.8, Sonnet 5, GPT-5.6)

Enterprise data handling

UiPath docs confirm: customer data is not used to train LLM models; data is not used to train third-party models with Autopilot for Everyone; data is stored per the tenant's data residency settings; customers can delete data via the UI or Support. ISO 42001 certification by Schellman, dated 2025-10-27 in the independent registry. The UiPath trust page was opened but its SOC 2/ISO 27001/FedRAMP lines were not individually confirmed.

Licensing and pricing

Confirmed on UiPath pricing page: Community free forever; Basic starting at $25 per month (Europe region, limited scale; page notes 'Basic is evolving, an updated plan offering is coming soon'); Enterprise contact sales. UiPath docs: Autopilot is not available on the Free plan and consumption depends on plan and licence (Basic, Plus, Pro, App Tester, App Test Developer), with Community drawing from Community Credits. The 7x/20x quota multiples and 0.2 Platform Units per Autopilot for Everyone action were not re-verified. Not bundled with Microsoft 365 or Google Workspace.

Integrations

Microsoft Teams, Slack and Microsoft 365 Copilot; Claude Code, Cursor and Codex coding agents; MCP plug-ins (per original research; not re-verified).

2025-2026 developments

Aug 2026 release notes: Autopilot coding agent GA in Studio Desktop and model refresh (Claude Opus 4.8, Sonnet 5, GPT-5.6). UiPath site now features Cartographer and Delegate as new products. ISO 42001 certified Oct 2025.

Best-fit handbook departments

56 Business Operations & Process Excellence fits strongly: Autopilot in Maestro converts process descriptions into BPMN and flows; SOP creation is indirect. No weak departments listed.

Listed for these departments in the handbook

56 Business Operations & Process Excellence

Training notes

Learners must distinguish Autopilot (assistive) from agents (autonomous), review generated workflows before publishing, test and validate, apply AI Trust Layer policies, track quota and Platform Unit consumption, and keep humans in the loop in Maestro. Advanced (56): 12-20 h covering Studio Web and Maestro authoring, BPMN basics, Orchestrator monitoring and Trust Layer administration.

Caveats

Per-user quotas and Platform Unit metering can surprise budgets; many 2026 features are preview; the Basic plan is being replaced; model deprecations can cause behaviour drift; enterprise pricing is quote-only.
