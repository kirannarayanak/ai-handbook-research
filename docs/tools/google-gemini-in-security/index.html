What it is

What the tool is and where it lives, in plain language.

Gemini-powered assistance and agents built into Google Security Operations (SIEM/SOAR) and Google Threat Intelligence. It generates detection rules and search queries, summarises and investigates cases, and runs a Triage and Investigation agent that judges whether alerts are true or false positives.

Vendor and product family
Google Cloud (Google Security Operations, Google Threat Intelligence, Mandiant; part of Google Unified Security)
Handbook category
Security & observability

Key capabilities

The main things it can do today.

  • Triage and Investigation agent that evaluates alerts and runs an investigation plan
  • Natural-language search and detection-rule generation
  • Case summaries and an investigative chat assistant with response recommendations
  • Threat-intelligence Q&A drawing on Mandiant intelligence
  • AI agents embedded in SOAR playbooks

Enterprise data handling

What happens to the information you type in: whether the vendor trains on it, where it is stored, how long it is kept, and which security standards it meets.

Applies to Gemini for Google Cloud. Google's data-governance page states prompts and responses are not used to train Gemini models; optional programmes share data for product improvement only. Gemini in SecOps requests may be routed to any available global region, so strict data residency is not guaranteed. Specific SOC 2, ISO and FedRAMP statements and retention periods for Gemini were not verified.

Licensing and pricing

How it is paid for: per user, per usage, or bundled with something you already own.

Google SecOps is sold in Standard, Enterprise and Enterprise Plus packages based on data ingestion, with 12 months of telemetry retention included. Per-package prices: contact sales. Which packages include Gemini features is not verified on an opened page. Google Unified Security bundles Enterprise Plus plus other products (not re-verified).

Integrations

The other systems it connects to, and which handbook departments that matters for.

Google SecOps SIEM and SOAR (700+ parsers, 300+ SOAR integrations), Google Threat Intelligence and Mandiant, Wiz for multicloud (Wiz not re-verified). Relevant to department 47.

Cloud Next 2026 (Apr): per CSO Online, threat hunting and detection engineering agents (preview) and a third-party context agent (entering preview). Note the brand is fragmented across Gemini in Security Operations, Gemini in Threat Intelligence and the Agentic SOC.

What a learner must be able to do, and how many hours to budget.

Learners must master YARA-L/UDM search basics, validating agent verdicts, playbook-embedded agents and regional-processing implications. Suggested 24-32 hours (Specialist band).

Jargon on this page

  • AgentAn AI that does not just answer but takes actions: runs code, opens tickets, sends messages, edits systems. Agents need an approval step for anything that cannot be undone.
  • PromptThe instruction or question you give an AI tool. Clear prompts with context and a desired format get better results.
  • TierThe handbook's training depth: Core (6-10 hours per tool), Advanced (12-20), Specialist (20-40+). A department's tier sets how long to budget.
  • VerifiedVerified means a researcher opened the page and read the claim on it. Not verified means it came from a search snippet or a page that would not load, so treat it with care.
  • Data residencyWhere your data is stored and processed. Some tools keep EU or UK data in Europe; some process everything in the US. This matters for privacy law.
  • RetentionHow long a tool keeps your prompts and outputs. Enterprise plans usually let an administrator set this.
  • SOCSecurity Operations Centre: the team that watches for cyber attacks. SIEM is the software that collects their security logs.
