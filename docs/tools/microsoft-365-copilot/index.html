Learning path and certifications

No official course or certification was found for this tool at the time of research. Start with the vendor documentation linked in the sources, then the shared foundation module.

What it is

An AI assistant embedded in Word, Excel, PowerPoint, Outlook, Teams, Loop and OneNote, plus the standalone Microsoft Copilot app (copilot.cloud.microsoft) with Chat, Search, Notebooks, Pages and agents. It grounds large language models in the user's Microsoft Graph content (mail, files, chats, meetings) while honouring existing permissions.

Vendor and product family
Microsoft (Microsoft Copilot family; product renamed from "Microsoft 365 Copilot" to "Microsoft Copilot" in August 2026, licences may still carry the old name)
Handbook category
Microsoft productivity & platform

Key capabilities

  • Graph-grounded chat with optional web grounding and citations
  • Researcher and Analyst reasoning agents producing reports, decks and data analyses
  • Copilot Notebooks and Pages for persistent, shareable working context
  • Edit with Copilot (Agent Mode) that makes multi-step changes inside Word, Excel and PowerPoint
  • Copilot Cowork task delegation and federated Copilot connectors over MCP (not verified against an opened page)
  • Agent Builder and declarative agents governed from the Microsoft 365 admin center

Enterprise data handling

Paid licence and no-cost Copilot Chat (Enterprise Data Protection): prompts, responses and Graph data are not used to train foundation models; data is covered by the DPA. Copilot surfaces only content the user can already view; admins get Purview retention, audit and eDiscovery over Copilot interactions. The EU Data Boundary does not apply to web search queries, and Anthropic-provided models are currently excluded from the EU Data Boundary and in-country processing commitments. Stated commitments include GDPR, ISO/IEC 27018, DPA and BAA; Microsoft Copilot is listed in the Office 365 FedRAMP scope pages. Other certifications (ISO 42001, SOC 2 Type 2) and the Multi-Geo/ADR date: not verified. Admins choose whether OpenAI or Anthropic subprocessor models are used.

Licensing and pricing

Add-on priced at USD 30 per user per month on annual commitment (USD 360/year) per an independent 2026 guide (EPC Group); Microsoft's own pricing page could not be retrieved. Included in Microsoft 365 E7 (USD 99 per user per month, launching 1 May 2026, per Directions on Microsoft; E7 bundles E5, Copilot, Agent 365 and Entra Suite per EPC). Copilot Business is an add-on for tenants up to 300 users with annual commitment (Learn; USD 21 per independent source). Prerequisite plans include M365 E3/E5/F1/F3, Business Basic/Standard/Premium, Office 365 E1/E3/E5 and others; GCC, GCC High and DoD add-ons exist (Learn). Copilot Chat is no-cost with eligible M365 subscriptions; usage-based billing details not verified.

Integrations

Microsoft Graph (Exchange, SharePoint, OneDrive, Teams), Copilot connectors, Power Platform connectors (separately licensed), Dataverse/Dynamics search, Purview, Planner agent, Copilot Analytics in Viva Insights.

2025-2026 developments

Aug 2026: app renamed Microsoft Copilot with new URL copilot.cloud.microsoft (rollout from mid-August, MC1454108, per futurework.blog); Learn docs state "Microsoft 365 Copilot is now named Microsoft Copilot". 1 May 2026: Microsoft 365 E7 launch with Copilot included. Agent Mode GA in Word/Excel/PowerPoint in April 2026 (exact date not verified). Later 2026 items (Cowork, Vision, model additions, Pages storage) not verified.

Best-fit handbook departments

Strong for Office of the CEO, Board Secretariat, HR Business Partnering, PMO, Sales, Legal drafting, Learning & Development and any role living in Outlook/Teams/Word. Weak fit where the listed task is structured-data or system-specific: Accounts Payable invoice extraction (Power Automate/AI Builder), Supply Chain demand insights and Enterprise Applications & ERP (Power BI/ERP tools), and specialist Regulatory Compliance control evidence.

Training notes

Learners must master grounding prompts with files and people, verifying citations, sensitivity labels and oversharing hygiene, when to use Researcher/Analyst versus chat, reviewing Agent Mode edits, and Notebooks. Core 6-10 hours for general users; Advanced 12-20 hours for agents, Notebooks and Analyst; Specialist 20-40 hours for Agent Builder, connectors and governance.

Caveats

Outputs are not guaranteed factual and must be reviewed. Permission hygiene is a prerequisite because Copilot exposes anything a user can already open. Government clouds lack Edit with Copilot (Learn service description). EU Data Boundary excludes Anthropic models and web queries. Annual commitment plus emerging usage-based billing complicates budgeting, and the 2026 rename causes documentation confusion. Price rests on independent sources.
