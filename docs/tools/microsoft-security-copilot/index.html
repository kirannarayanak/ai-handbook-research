What it is

What the tool is and where it lives, in plain language.

A generative-AI security assistant and agent platform. It works in a standalone portal and embedded inside Defender, Entra, Intune and Purview. It summarises incidents, guides investigations and runs autonomous agents such as Phishing Triage and Conditional Access Optimization.

Vendor and product family
Microsoft (Microsoft Security product family: Defender, Entra, Intune, Purview, Sentinel)
Handbook category
Security & observability

Key capabilities

The main things it can do today.

  • Incident and alert summarisation with step-by-step response guidance
  • Embedded agents in Defender, Entra, Intune and Purview (phishing triage, vulnerability remediation, alert triage)
  • Promptbooks and a standalone natural-language investigation workspace
  • Partner-built and community-built (no-code) agents
  • Cross-product context spanning identities, devices, data, clouds and apps

Enterprise data handling

What happens to the information you type in: whether the vendor trains on it, where it is stored, how long it is kept, and which security standards it meets.

Applies to the commercial service. Customer Data is stored in the Workspace geo chosen at onboarding, which cannot be changed afterwards. Docs state data is not shared with OpenAI or used to train the Azure OpenAI foundation model. A separate data-sharing setting is ON by default for customers without an M365 E5/E7 licence (E5/E7 customers have different defaults per the Learn page). If opted in, prompts and responses go to Microsoft for product improvement and may be stored outside the chosen geo, and uploaded-file content may be human-reviewed. Admins (Global Admin, Security Admin with Capacity Contributor) can change it. Customer Data is deleted within 180 days of removing all provisioned capacity, and session data after 180 days of inactivity. Agent emails or Teams messages can cross geographic boundaries in transit. SOC 2, ISO 27001 and HIPAA attestations were not verified on opened pages.

Licensing and pricing

How it is paid for: per user, per usage, or bundled with something you already own.

Standalone: provisioned capacity in Security Compute Units (SCUs). The worked example on the pricing page uses USD 4 per provisioned SCU per hour (billed monthly) and USD 6 per overage SCU, minimum 1 SCU. Included at no added cost for eligible Microsoft 365 E5 and E7 customers: 400 SCUs per month per 1,000 paid user licences, capped at 10,000 SCUs per month, on a phased rollout that began 18 Nov 2025.

Integrations

The other systems it connects to, and which handbook departments that matters for.

Microsoft Defender, Entra, Intune, Purview and Sentinel; partner-built agents. ServiceNow-style ticketing integration was not verified. Relevant to departments 45, 47 and 48 through embedded Purview and Entra agents.

2025-2026 developments

What changed recently, including renames and products being retired.

Nov 2025 (Ignite): Security Copilot bundled into Microsoft 365 E5, later extended to E7. About a dozen new agents embedded in Defender, Entra, Intune and Purview. Microsoft markets the product around agents rather than the earlier chat-assistant framing.

Best-fit handbook departments

Which departments get the most from it, and where it is a weak fit.

47 Cybersecurity Operations (best fit: triage, hunting, incident summaries). 48 Security Governance, Risk & Privacy fits via the Purview and Entra agents. 45 IT Infrastructure is a weaker fit, limited to Intune and Entra device and identity tasks.

Training notes

What a learner must be able to do, and how many hours to budget.

Learners must master prompt scoping, reading agent evidence and verdicts, SCU consumption monitoring, role and permission setup, and the data-sharing setting. Suggested 24-32 hours (Specialist band), including supervised alert-triage labs.

Caveats

The things most likely to go wrong or surprise a buyer.

Value depends on the Microsoft security stack being deployed. SCU consumption is hard to forecast. The E5 inclusion is phased, so some tenants may not yet have it. The data-sharing default is ON for non-E5/E7 customers and should be reviewed by privacy teams. Outputs can be wrong and need analyst validation.

Jargon on this page

  • AgentAn AI that does not just answer but takes actions: runs code, opens tickets, sends messages, edits systems. Agents need an approval step for anything that cannot be undone.
  • PromptThe instruction or question you give an AI tool. Clear prompts with context and a desired format get better results.
  • TierThe handbook's training depth: Core (6-10 hours per tool), Advanced (12-20), Specialist (20-40+). A department's tier sets how long to budget.
  • VerifiedVerified means a researcher opened the page and read the claim on it. Not verified means it came from a search snippet or a page that would not load, so treat it with care.
  • CopilotMicrosoft's name for its AI assistants inside Word, Excel, Teams, Power BI, security tools and Azure. One licence covers several of them.
  • SOCSecurity Operations Centre: the team that watches for cyber attacks. SIEM is the software that collects their security logs.
  • Credits / SCUsMany AI features are not priced per user but by usage, measured in credits or compute units. Costs can rise with use and need monitoring.
