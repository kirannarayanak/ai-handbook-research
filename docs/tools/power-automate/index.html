Learning path and certifications

No official course or certification was found for this tool at the time of research. Start with the vendor documentation linked in the sources, then the shared foundation module.

What it is

A low-code automation service combining cloud flows (API and connector-based), desktop flows (robotic process automation), process and task mining, AI Builder document processing and a Copilot that builds flows from natural language. It lives in the Power Automate web portal and Teams app, the Power Automate for desktop application, and increasingly as agent flows inside Copilot Studio.

Vendor and product family
Microsoft (Microsoft Power Platform)
Handbook category
Microsoft productivity & platform

Key capabilities

  • Cloud flows over more than 1,000 API connectors (SharePoint, Outlook, Teams, Dataverse, SAP, Salesforce, ServiceNow) with approvals
  • Attended, unattended and Microsoft-hosted RPA for legacy systems
  • Process and task mining
  • AI Builder document and invoice processing, prompts and classification, consuming Copilot Credits
  • Copilot in the cloud-flow designer (not verified)
  • Governance via Managed Environments, DLP policies and audit logs (not verified)

Enterprise data handling

Copilot runs on Azure OpenAI within Azure; prompts and outputs are not used to train Microsoft or third-party models unless the tenant admin opts in; no storage or eyes-on review of inputs/outputs for abuse monitoring (Learn FAQ). Generally available Copilot features are on by default, and cross-region data movement may need admin allowance (Learn). Dataverse encryption, Purview 90-day audit retention, FedRAMP High/DISA levels, SOC 2/ISO scope and GCC availability: not verified.

Licensing and pricing

Per Microsoft pricing page (paid yearly): Premium USD 15 per user per month; Process USD 150 per bot per month; Hosted Process USD 215 per bot per month; Process Mining add-on USD 5,000 per tenant per month (Premium only). Process licence entitles cloud flows to 250,000 actions per day (Learn). Pay-as-you-go USD 0.60 per premium cloud flow run per independent FlowForma. Agent flows bill 13 Copilot Credits per 100 actions per independent BabyBots (free exemption for M365 Copilot users via agent trigger per same source). Seeded AI Builder credits and add-ons reach end of life 1 November 2026, replaced by Copilot Credits (Learn). Per-user daily action limits (40k/6k) not verified.

Integrations

SharePoint, Outlook, Teams, Forms, Dataverse, Dynamics 365, SAP and Salesforce connectors; AI Builder for AP invoice extraction; Copilot Studio agents calling flows.

2025-2026 developments

AI Builder credits end-of-life 1 Nov 2026 (announced Oct 2025, Learn). Agent flows in Copilot Studio (Learn). Other dated 2026 items (process mining GA, connector policies, desktop flow versioning, release-plan archive) not verified.

Best-fit handbook departments

Business Operations & Process Excellence is the strongest fit (process mining plus automation). Accounts Payable & Receivable fits for invoice extraction and exception routing but now carries Copilot Credit costs. Workplace Administration & Facilities fits for request routing and notifications, though organisations with ServiceNow may route tickets there instead.

Training notes

Learners must master triggers, actions and connectors, error handling and retries, solution-aware flows, environment and DLP strategy, licensing and request limits, RPA basics, AI Builder credit consumption, and reviewing Copilot-generated flows before saving. Core 6-10 hours for approvers and consumers; Advanced 12-20 hours for makers; Specialist 20-40 hours for RPA, process mining and Centre of Excellence roles.

Caveats

Licensing is complex: premium connectors, request limits and the AI Builder-to-Copilot-Credits shift can raise costs (the 2-4x figure is unverified). Third-party connectors move data outside Microsoft's compliance boundary. Agent flows consume Copilot Credit capacity. Several compliance and government-cloud claims were removed as unverified.
