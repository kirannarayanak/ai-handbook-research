What it is

AI features built into Figma's design platform (Make prompt-to-app, Weave media workflows, agents, Dev Mode MCP server), access by seat type and metered by monthly AI credits.

Vendor and product family
Figma, Inc. 'Figma AI' is the umbrella for AI across Figma Design, Make, Weave, Dev Mode, Motion, Sites, Buzz, Draw, Specs, FigJam and Slides.
Handbook category
Presentation, design & documents

Key capabilities

  • Figma Make prompt-to-code prototypes and apps
  • Weave AI workflows for imagery, video and audio
  • Dev Mode with MCP server
  • Agent and Code Layers features announced at Config (Jun/Oct 2026)
  • Figma Specs (beta)

Enterprise data handling

Verified (Figma help centre): content training is on by default for Starter and Professional (admins can toggle off); off by default for Organization and Enterprise and currently cannot be toggled on. Admins can enable AI features per team, workspace or organization. Figma security page confirms SOC 2 Type 2, SOC 3, ISO/IEC 27001:2022, ISO/IEC 27018:2019, ISO/IEC 42001:2023 and EU Cloud Code of Conduct, C5 listed. ISO 27017/27701, FedRAMP, TISAX, EU hosting and Governance+ details were not confirmed in the text read.

Licensing and pricing

Verified (Figma pricing page, USD, prices in USD): Starter free, 150 AI credits/day up to 500/month; Professional Full $16 (3,000 credits), Dev $12 (500), Collab $3 (500); Organization (annual) Full $55 (3,500), Dev $25, Collab $5; Enterprise (annual) Full $90 (4,250), Dev $35, Collab $5. Credit rollover, per-prompt costs and 'no separate SKU' claims not re-verified; pricing page mentions 'New AI add-ons are now available for all plans'.

Integrations

Dev Mode MCP server (pricing page); other partners not re-verified.

2025-2026 developments

14 Oct 2026 TechCrunch article on new features for agents (opened); Config 2026 recap blog (opened). Specific items (Agent GA 24 Jun 2026, Code Layers beta) not individually re-checked.

Best-fit handbook departments

Product Design & UX Research; Product Management (Make prototypes); Engineering (Dev Mode MCP).

Training notes

Design-system-grounded prompting, Make iteration and code review, credit budgeting and admin caps, MCP/agent governance, plan-level training settings. Advanced 12-20 hours; Specialist 20-30 hours.

Caveats

Credit consumption varies; Organization/Enterprise are annual only; many features beta; Professional trains on content unless disabled; agent-generated code needs security review.
