What it is

The AI layer built into Jira Cloud (and Confluence, Jira Service Management, Loom). It appears inline in work items, search, the automation builder and a Rovo Chat panel, with Rovo Agents and Rovo Studio for custom agents. Cloud only.

Vendor and product family
Atlassian Corporation. In-product AI is now marketed as Rovo; 'Atlassian Intelligence' persists as the legacy name.
Handbook category
Enterprise business platforms

Key capabilities

  • Natural-language search and JQL generation
  • Summaries of comments, work items and smart links; AI writing and editing
  • Task suggestions and work breakdown, field value recommendations, duplicate detection
  • Natural-language creation of automation rules
  • Rovo Chat, Rovo Agents, Rovo Studio, Rovo Dev; Virtual Service Agent in JSM

Enterprise data handling

Atlassian AI transparency page confirms inputs and outputs are not used to improve any large language models and are retained by Atlassian for 30 days for safety and security purposes. Zero-retention statements for named LLM providers, SOC 2 scope for Rovo, auto-enablement by plan, and AI data residency were not re-verified or not visible on pages opened. LLM routing is Atlassian's choice (per original research).

Licensing and pricing

Per Breeze (third party, matches Adaptavist's +7-10% Standard/Premium and +8% Enterprise rise for Oct 2026): Standard $9.05 to $9.70 and Premium $18.30 to $19.60 per user per month at the stated band; Atlassian's Premium page says Premium is about 2x current average cost per user and cheaper as you add users. Rovo usage-limits page confirms 25/70/150 credits per user (Standard/Premium/Enterprise columns) and that extra-usage billing for Rovo credits takes effect 3 Dec 2026. The USD 0.01 per credit overage and USD 0.50 per 1,000 automation steps are not verified. Free plan has no AI (not re-verified). Not bundled with Microsoft 365 or Google Workspace.

Integrations

Confluence, Jira Service Management, Loom, Bitbucket, GitHub, Google and Microsoft connectors, MCP server for external assistants (per original research; not re-verified).

2025-2026 developments

Rovo included in paid Jira and Confluence plans. Usage-based billing begins 3 Dec 2026 (Rovo usage-limits page). Oct 2026 price rises (Adaptavist, Breeze). 'Atlassian Intelligence' is being superseded by 'Rovo'.

Best-fit handbook departments

39 Product Management (work breakdown, summaries, automation generation) and 54 PMO (status and dependency summaries, Rovo agents for reports) both fit; 54 is weaker where cross-project dependency analysis needs Plans or Jira Align, which require Premium or above.

Listed for these departments in the handbook

Training notes

Learners must know which actions consume credits, verify generated JQL and summaries, keep sensitive data out of prompts where instance permissions are broad, build automation rules safely and understand admin spend caps. Core (39, 54): 6-10 h; add 4-6 h for Rovo Studio agent building.

Caveats

Cloud only; overage billing starts Dec 2026 so admins must set caps; credit cost varies by feature; exact official per-user prices come from independent sources; ISO 42001 certification for Atlassian was not found in the registry checked.
