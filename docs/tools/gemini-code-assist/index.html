What it is

Enterprise AI coding assistant for VS Code, JetBrains, Android Studio, Cloud Shell Editor and Cloud Workstations, with GitHub pull-request review and the Gemini CLI. Sold as Standard and Enterprise editions; the Individuals and Google AI Pro/Ultra IDE tiers stopped June 18 2026.

Vendor and product family
Google (Google Cloud, 'Gemini for Google Cloud' family). Rename/sunset flag: Google now sells agentic coding as Google Antigravity inside Gemini Enterprise editions.
Handbook category
Coding & engineering

Key capabilities

  • Code completion, generation, chat with open-file context and smart actions
  • Agent mode (widely available since Aug 2025) for multi-step edits and commands
  • Enterprise code customization from private repos with CMEK
  • Google Cloud hooks: Firebase, BigQuery, Cloud Run, Database Studio; Enterprise adds Apigee, Application Integration and Gemini Cloud Assist
  • GitHub Enterprise code review; release channels; Cloud console admin

Enterprise data handling

Google states Gemini for Google Cloud does not use prompts or responses to train models (data governance page: used for improvements, not for training Gemini models). Licences are assigned through the Cloud console and IAM. CMEK for customization data, IP indemnification, source citations and SOC/ISO/FedRAMP were not confirmed on pages opened in this check.

Licensing and pricing

No official price page opened. An Oct 2025 independent review (Cloudchipr) lists Standard US$22.80 and Enterprise US$54 per user per month (annual discounts not verified). Per Google's sunset page (updated 2026-10-22): no new Standard/Enterprise subscriptions since Oct 9 2026; licences can be added and annual plans renewed until Jan 31 2027, monthly plans renewed until Dec 31 2027. Antigravity is included in Gemini Enterprise editions.

Integrations

Google Cloud (BigQuery, Cloud Run, Firebase, Apigee), GitHub/GitLab/Bitbucket repositories, GitHub Enterprise PR reviews, MCP servers, Gemini CLI GitHub Actions (not individually re-verified).

2025-2026 developments

Jun 8 2026: Gemini 3.5 Flash GA. Jun 18 2026: Individuals and Google AI Pro/Ultra IDE tiers stopped, users sent to Antigravity. Oct 9 2026: end of sale for Standard/Enterprise. Gemini CLI to Antigravity CLI migration guide published.

Best-fit handbook departments

43 Cloud (GCP-native teams) fits best while contracts run; 41 and 44 adequate via Cloud Assist; 42 weak (no dedicated test agents). Treat all as transitional and plan Antigravity training.

Listed for these departments in the handbook

41 Software Engineering - Applications42 Quality Engineering & Testing43 Cloud Infrastructure & Platform Engineering44 DevOps & Site Reliability Engineering

Training notes

Agent-mode controls, customization scope, citation checking, Cloud console licensing. Core 6-8 h (41); Advanced 12 h (42, 44); Specialist 20 h for 43 GCP platform teams including migration to Antigravity CLI and IDE extensions.

Caveats

End of sale; no published price mapping to Gemini Enterprise; unclear whether customization settings transfer to Antigravity. Pricing is third-party and dated. New buyers cannot purchase either edition.
