What it is

What the tool is and where it lives, in plain language.

Agentic coding tool that reads a codebase, edits files, runs commands and opens pull requests. Surfaces: terminal CLI, VS Code and JetBrains extensions, desktop app, web (claude.ai/code) and mobile, plus Slack, GitHub Actions/GitLab CI and an Agent SDK.

Vendor and product family
Anthropic (Claude product family). Bundled in Claude Pro, Max, Team and Enterprise; also pay-as-you-go via Anthropic Console, Amazon Bedrock, Google Cloud Agent Platform (renamed from Vertex AI) and Microsoft Foundry.
Handbook category
Coding & engineering

Key capabilities

The main things it can do today.

  • Multi-file edits under permission modes: auto (a classifier screens actions), manual, sandboxed bash
  • Subagents, dynamic workflows and a Projects coordinator for long-running parallel work
  • CLAUDE.md memory, skills, hooks, plugins and MCP connectors
  • GitHub Code Review (GA Oct 2026) with Quick/Standard/Deep levels
  • Scheduled routines, Remote Control, cloud sessions and CLI piping for CI and log triage

Enterprise data handling

What happens to the information you type in: whether the vendor trains on it, where it is stored, how long it is kept, and which security standards it meets.

Team, Enterprise, API and cloud-provider deployments: Anthropic does not train on code or prompts unless the org opts into the Development Partner Program (first-party API only); 30-day standard retention; zero data retention is available to qualified accounts on Claude for Enterprise, enabled per organization by the account team (not included in the standard plan). Free/Pro/Max: training only if the user enables it (5-year retention on, 30 days off). Enterprise adds SSO, SCIM, RBAC, audit logs, compliance API, custom retention and a HIPAA-ready offering (per the pricing page); managed settings enforce policy. IP allowlisting, CMEK, US-only inference, BAA terms, and the SOC 2 Type 2 / ISO 27001 reports on the Trust Center were not verified in this check.

Licensing and pricing

How it is paid for: per user, per usage, or bundled with something you already own.

USD: Pro $20/month ($17 annual); Max from $100 (5x) up to $200 (20x)/month; Team (2 to 150 seats) Standard seat $25/month or $20 annual, Premium seat $125/$100; Enterprise $20/seat/month billed annually (20-seat self-serve minimum; 50-seat minimum sales-assisted) plus all usage at API rates. Not bundled with any office suite.

Integrations

The other systems it connects to, and which handbook departments that matters for.

Git, GitHub, GitLab, GitHub Actions, GitLab CI/CD, Slack, Chrome debugging, OpenTelemetry, MCP servers (Jira, Google Drive, Datadog, PagerDuty, Zapier, Workato, Notion, Asana), LLM gateways. Specific MCP server list not re-verified.

Training notes

What a learner must be able to do, and how many hours to budget.

Master permission modes and auto-mode risk, CLAUDE.md, plan-then-execute, diff review, MCP trust, sandboxing and usage monitoring. Core 8-10 h (41); Advanced 14-18 h (42, 44); Specialist 24-32 h (43, 49, 51: Agent SDK, Bedrock/Foundry deployment, OpenTelemetry).

Caveats

The things most likely to go wrong or surprise a buyer.

Enterprise usage is metered at API rates, so spend limits matter; usage limits reset on a rolling five-hour window plus weekly limits. Vendor states no system is immune to prompt injection. Feature availability differs by provider; supported-countries list applies.

Jargon on this page

  • AgentAn AI that does not just answer but takes actions: runs code, opens tickets, sends messages, edits systems. Agents need an approval step for anything that cannot be undone.
  • PromptThe instruction or question you give an AI tool. Clear prompts with context and a desired format get better results.
  • Prompt injectionA trick where text inside an email, web page or document secretly instructs an AI agent to do something harmful. It is why agents should not act on content you do not trust.
  • TierThe handbook's training depth: Core (6-10 hours per tool), Advanced (12-20), Specialist (20-40+). A department's tier sets how long to budget.
  • VerifiedVerified means a researcher opened the page and read the claim on it. Not verified means it came from a search snippet or a page that would not load, so treat it with care.
  • RetentionHow long a tool keeps your prompts and outputs. Enterprise plans usually let an administrator set this.
  • Training on your dataWhether the vendor uses what you type to improve its AI model. Business and enterprise plans almost always say no by default; free consumer plans often say yes.
  • MCPModel Context Protocol: a standard way to connect an AI tool to other systems (files, tickets, databases). Powerful, so access should be scoped carefully.
