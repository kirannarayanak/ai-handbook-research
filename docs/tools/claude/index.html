What it is

What the tool is and where it lives, in plain language.

General AI assistant and agent platform. Surfaces: web, desktop, mobile, Chrome extension, Microsoft 365 and Google Workspace add-ins. Anthropic's pricing page notes Claude Cowork is now just Claude (rolling out to Pro and Max first). The same models are sold via API.

Vendor and product family
Anthropic PBC. Family: Claude Free/Pro/Max, Team and Enterprise (Claude for Work), Claude Code, Claude Cowork, Design, and the Claude Platform (API).
Handbook category
General AI assistant

Key capabilities

The main things it can do today.

  • Projects, memory across conversations, Artifacts
  • Connectors (apps and tools), enterprise search, Claude Code, Claude in Chrome and Microsoft 365 add-ins (per pricing page)
  • Claude Design, Slides, Docs; skills and plugins
  • Enterprise deployment of the desktop app

Enterprise data handling

What happens to the information you type in: whether the vendor trains on it, where it is stored, how long it is kept, and which security standards it meets.

Commercial products (Claude for Work, API): inputs/outputs not used for training by default; if feedback (thumbs up/down) is submitted the conversation can be used for training and stored up to 5 years; Owners can disable feedback via the Rate chats setting. Consumer Free/Pro/Max follow a separate consumer policy (not re-checked beyond the pointer on the commercial page). Certifications listed by Anthropic: HIPAA-ready configuration (BAA available), ISO 27001:2022, ISO/IEC 42001:2023, SOC 2 Type I & II. FedRAMP High/DoD IL4-5, CSA STAR, CMEK, SCIM, audit logs and Compliance API: not verified (Trust Center page returned no text).

Licensing and pricing

How it is paid for: per user, per usage, or bundled with something you already own.

USD per pricing page: Free $0; Pro $17/month annual ($200 up front) or $20 monthly; Max from $100 (5x and 20x tiers, $100/$200). Team (2 to 150 seats): Standard $20/seat/month annual or $25 monthly; Premium $100 annual or $125 monthly. Enterprise: US$20/seat/month billed annually, 20-seat minimum, plus usage at API rates.

Integrations

The other systems it connects to, and which handbook departments that matters for.

Microsoft 365 (incl. Outlook), Chrome, connectors and MCP; API via Anthropic. Availability on AWS Bedrock, Google Cloud, Microsoft Foundry and a list of named apps (Salesforce, Figma, Canva etc.): not verified.

What changed recently, including renames and products being retired.

Pricing page: Claude Cowork is now just Claude; Claude Dashboards (beta), Claude Science, Claude Duet and Claude Tag appear in the product menu. Detailed model release timeline, retirement dates, revenue figure and Oct 2026 items from the earlier draft: not verified.

Training notes

What a learner must be able to do, and how many hours to budget.

Prompting with Projects, connector scopes, verifying citations and numbers, artifact/file workflows and skills; admins learn retention and feedback settings; technical roles add Claude Code. Core 6-10 h; Advanced 12-18 h; Specialist 24-40 h.

Caveats

The things most likely to go wrong or surprise a buyer.

Enterprise usage is billed at API rates on top of seats; 20-seat annual minimum; consumer training defaults differ, so block personal accounts; HIPAA only via BAA-configured Enterprise/API; frequent model deprecations; Trust Center documents are gated.

Jargon on this page

  • AI assistantA tool you talk to in plain language (Claude, Gemini, ChatGPT, Microsoft Copilot). It drafts, summarises and answers, but it can be wrong, so you check its work.
  • AgentAn AI that does not just answer but takes actions: runs code, opens tickets, sends messages, edits systems. Agents need an approval step for anything that cannot be undone.
  • PromptThe instruction or question you give an AI tool. Clear prompts with context and a desired format get better results.
  • TierThe handbook's training depth: Core (6-10 hours per tool), Advanced (12-20), Specialist (20-40+). A department's tier sets how long to budget.
  • VerifiedVerified means a researcher opened the page and read the claim on it. Not verified means it came from a search snippet or a page that would not load, so treat it with care.
  • RetentionHow long a tool keeps your prompts and outputs. Enterprise plans usually let an administrator set this.
  • MCPModel Context Protocol: a standard way to connect an AI tool to other systems (files, tickets, databases). Powerful, so access should be scoped carefully.
  • SOCSecurity Operations Centre: the team that watches for cyber attacks. SIEM is the software that collects their security logs.
