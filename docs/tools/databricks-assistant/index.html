What it is

Databricks Assistant was renamed Genie Code in March 2026 and became an autonomous agent for data teams. It runs inside the Databricks workspace (notebooks, SQL editor, Lakeflow Pipelines Editor, AI/BI dashboards, MLflow). It plans multi-step tasks, writes and runs code, and fixes errors, within the user's Unity Catalog permissions.

Vendor and product family
Databricks. Now marketed as Genie Code, part of the Databricks Genie family. The brief's name is out of date.
Handbook category
Data, analytics & AI platforms

Key capabilities

  • Generates, runs and debugs SQL and Python in notebooks and the SQL editor
  • Builds and maintains Lakeflow/Spark Declarative Pipelines and monitors them for failures
  • Creates AI/BI dashboards and exploratory analyses from natural language
  • Agent plans for review before execution, custom instructions, agent skills and MCP connections
  • Scheduled tasks (Beta) and an agentic converter (Beta) for legacy SQL dialects

Enterprise data handling

Per Databricks' trust page (the claim that it applies to all tiers is not verified). Databricks does not use prompts, data or responses to train generative foundation models offered to third parties. Partner model providers (Azure OpenAI, OpenAI on Databricks, Anthropic on Databricks) use zero data retention endpoints. All data sent respects Unity Catalog permissions. Traffic uses TLS and workspace data is AES-256 encrypted; customer-managed keys are not verified here. Genie Code is a Designated Service that follows Geo data residency; in-country routing was added in March 2026 for Brazil, Canada, Japan, Korea, Singapore and the UK. The trust page has a section on PHI, PCI, IRAP and FedRAMP data; the compliance security profile requirement is not verified in detail. From July 2026, HIPAA-profile workspaces can use it only with partner-powered AI disabled, so the Databricks-hosted model serves it. By default an AI classifier auto-approves the agent's actions; users can switch to manual approval.

Licensing and pricing

No per-seat list price was found. Since 8 July 2026 Genie Code is pay-as-you-go with a per-user monthly free allowance, managed through account budgets. The size of the allowance is not verified. Genie One and Genie Agents are free for users through 31 January 2027 (service principals excluded and billed). It is not bundled with a suite; it requires a Databricks workspace.

Integrations

Unity Catalog, Lakeflow, AI/BI dashboards and MLflow. MCP connections are supported; the specific Jira, Confluence and GitHub connectors are not verified. Relevant to dept 49 Data Engineering.

2025-2026 developments

RENAME: Databricks Assistant is now Genie Code (March 2026), with agentic capabilities. Pay-as-you-go billing began 8 July 2026. HIPAA-profile support (partner AI off) and scheduled tasks (Beta) arrived in July 2026. In-country AI routing was added in March 2026.

Training notes

Learners need Unity Catalog permissions, prompt and plan review, approval modes, and testing of generated code before production. Suggested 24-32 hours (Specialist band).

Caveats

Agentic features need partner-powered AI enabled and a supported region. Auto-approve mode can execute code, so choose approval mode deliberately. Databricks warns that output can be wrong. Usage is metered, so cost controls matter.
