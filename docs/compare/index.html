Compare

Side by side, up to four at once

Pick tools to compare pricing models, data handling, confidence and department fit. Or switch to departments to compare tiers, tool lists, capstones and data rules. Share the URL to keep the selection.

First time here? How to compare (click to hide; stays hidden on this browser)
  1. 1
    Choose tools or departments

    The switch below changes what you compare. Tools line up pricing, data handling and fit; departments line up tier, tool lists, capstones and data rules.

  2. 2
    Add up to four

    Type a name in the box and pick from the list, or click a preset such as 'General assistants'. Remove one with the cross.

  3. 3
    Read down each column

    Rows are the same for every item, so you can scan one attribute across all of them. The web address updates, so you can share the comparison.

    Presets:{''.join(f'' for n, p in presets)}
