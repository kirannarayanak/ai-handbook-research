Department 42 · Engineering, cloud and IT

Quality Engineering & Testing

Test case generation, automation scripts, defect triage

Advanced · 12-20 hMedium confidenceEngineering, cloud and IT
Compare this department Show in matrix

Recommended tools

From the handbook. Tier Advanced, 12-20 h per tool as a planning band.

Claude CodeGemini Code AssistGitHub CopilotPlaywrightChatGPT Enterprise

AI use cases in practice

  • Test case design and requirements refinement with an LLM assistant; the World Quality Report 2025 says these now lead GenAI adoption in quality engineering [1].
  • Generating first-draft Playwright or Selenium specs from a prompt, user story or recording; reviewers must make each test fail before trusting it [2].
  • Self-healing locators that repair selectors when markup changes; each heal should be reviewed, as it can hide a regression [2].
  • Failure triage that turns a wall of failed tests into a probable cause [2].
  • Test selection and flake detection to decide what to run and what to trust; keep a scheduled full run as a backstop [2].
  • Defect analysis and reporting, the earlier GenAI use now being overtaken by input-side work such as test design [1].

Capstone deliverable

Within about 12 hours: take one real user story, produce an AI-drafted Playwright suite of at least 10 tests, and show that each test fails against a deliberately broken build before it passes. Submit the prompt log, a review checklist covering hallucinated selectors and assertions, a heal-review record, and measured time versus manual authoring.

Data risks and rules

Test environments often hold copies of production data, including personal data (GDPR), payment card data (PCI DSS) and health data (HIPAA). Rules: use synthetic or masked data in prompts, never paste credentials or proprietary source into unsanctioned tools, and keep a human reviewer for all generated tests. The WQR 2025 ranks data privacy (67%) and hallucination or reliability (60%) among the top barriers [1].

Adoption KPIs

1) Share of new tests drafted with AI and merged after review. 2) Test authoring time versus baseline (WQR reports an average 19% productivity gain, with one third seeing minimal gains [1]). 3) Flaky-test rate and failures triaged per engineer. 4) Escaped-defect rate for AI-assisted versus manual suites. 5) Healed locators reviewed within one sprint (%).

Curriculum emphasis

Most hours on prompting for test design and on validating AI output (mutation and fail-first checks), because generated tests can be confidently wrong [2]. Prioritise Playwright (the execution target), GitHub Copilot or Claude Code (drafting and refactoring specs) and ChatGPT Enterprise (requirements refinement). Spend little time on self-healing until locator hygiene is covered; the source notes stable test ids fix the same brittleness permanently [2].

Tool-list fit

The list fits well: Playwright is a framework rather than an AI tool, but it is the natural target for generated tests. Gemini Code Assist is a generic coding assistant with no testing-specific evidence found. Omitted: AI-native testing platforms such as OpenText, Tricentis and mabl. The WQR press release notes OpenText was recognised as a Leader in the 2025 Gartner Magic Quadrant for AI-Augmented Software Testing Tools [1]; Tricentis and mabl were not verified from an opened page. Note the WQR is co-published by OpenText, a vendor in this space.
