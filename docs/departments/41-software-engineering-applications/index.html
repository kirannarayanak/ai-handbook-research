AI use cases in practice

  • Inline code completion and chat in the IDE with GitHub Copilot. A Zoominfo rollout to more than 400 developers measured acceptance rates (33% of suggestions, 20% of lines of code) and satisfaction. [1]
  • Developers self-reported a median 20% reduction in task time, with 77% saying work quality improved. These are survey results, not measured output. [1]
  • A randomized controlled trial at Accenture used DevOps telemetry plus a survey and found high adoption and satisfaction. The 'up to 55% faster' figure comes from GitHub's earlier lab studies, which the same post cites, not from the Accenture trial. This is vendor-run research. [2]
  • Generating unit tests, debugging and documenting code in the IDE with Gemini Code Assist, which cites sources when it quotes at length. [3]
  • Agentic coding in the terminal or IDE with Claude Code, using checkpoints to rewind changes. Subagents and hooks are described as Agent SDK support for custom workflows. [4]
  • Code review support: Zoominfo flagged limits in domain-specific context and the need to vet generated code. [1]

Capstone deliverable

Refactor or document one real module (non-production data) using an approved assistant. Deliver the merged pull request, a prompt log, the tests that gate it, a security review of the AI-generated diff, and a measured before-and-after time comparison against a similar manual task. Assessed against a rubric on correctness, test evidence and honest reporting of rework.

Data risks and rules

Source code, credentials and API keys, proprietary algorithms and customer data in test fixtures. Rules: no secrets or production data in prompts; use enterprise-licensed tools with data-retention terms checked; review licence and citation flags on suggestions; treat generated code as untrusted until tested and scanned. Regulatory hooks (GDPR for personal data in fixtures) apply but were not covered by sources.

Adoption KPIs

Weekly active users as a share of licences; suggestion acceptance rate; pull request cycle time against a pre-rollout baseline; developer satisfaction survey score; defect or revert rate on AI-assisted changes.

Curriculum emphasis

Core tier, so most hours go to hands-on practice, then a short module on risk. Prioritise GitHub Copilot (the most evidence of enterprise rollout), Claude Code (agentic multi-file work with verification) and Gemini Code Assist (a Google Cloud shop). Spend a block on verification habits: run tests, review diffs, never accept blindly.

Tool-list fit

Good fit overall. Gemini Code Assist's own documentation says new Standard and Enterprise subscriptions are no longer available for purchase, so confirm availability before teaching it. [3] Cursor is listed but no opened page covers it: not verified. ChatGPT Enterprise is a general assistant and is a weaker fit for IDE work than the others (not verified).
