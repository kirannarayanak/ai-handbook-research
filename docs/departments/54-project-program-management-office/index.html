What to learn, in order

Foundation first, then the general assistant, then the productivity surfaces, then the specialist platform. Each step links to the tool's official courses and certifications. Planning total: about 22-66 hours including the shared foundation module, less overlaps within one licence.

AI use cases in practice

  • Drafting project status updates from Rovo chat in Jira (Rovo Project Management skills: create work items, update work items, draft status updates). [1]
  • Summarising a Jira work item's status, contributors, next steps, blockers and recent updates for fast catch-up. [1]
  • Breaking work down into manageable tasks with summaries and descriptions via Rovo's work breakdown. [1]
  • Checking that work is clear and complete before planning via a 'Work Readiness Checker' agent, which Atlassian says reduces wasted work and follow-up meetings (vendor claim). [1]
  • Dependency and risk summaries from exported plans using a general LLM: not verified.

Capstone deliverable

A weekly portfolio status pack for a real or realistic 3-project portfolio. It contains an AI-drafted status report per project, a dependency and risk summary, and a one-page executive view. Each project's figures are validated against the source tracker. The deliverable includes a documented prompt library and a measured time-saved log (baseline versus AI-assisted). Core-tier hours.

Data risks and rules

Project plans, budgets, vendor contracts and unannounced strategic initiatives are confidential. Resource data (names, utilisation) is personal data under GDPR and employment law. Rules: use only the enterprise-licensed assistant, exclude M&A or other MNPI-bearing projects from non-approved tools, and have a human owner verify every figure before it reaches a steering committee. The Atlassian page states privacy-by-design and that organisation admins can deactivate AI [1]; contractual data terms are not verified.

Adoption KPIs

Percentage of status reports AI-assisted; hours to produce the weekly report (baseline versus now); report factual-error rate found on review; share of PMs trained and active weekly; reduction in status meetings or follow-up queries.

Curriculum emphasis

Mostly hands-on: status and risk summarisation, prompt templates, verification against tracker data. Prioritise Jira Atlassian Intelligence (in-system data; it is where status data lives), Microsoft 365 Copilot (meeting and email context), and Claude or Gemini (long-document synthesis). Defer Gamma and Power BI Copilot to a short module.

Tool-list fit

The list is a good fit. Jira's AI is the natural core, and the Atlassian page shows status drafting and summaries [1]. Gamma is useful for decks but secondary. The Atlassian page brands these features as Rovo, which the handbook's name 'Jira Atlassian Intelligence' may not reflect [1]; other PPM tools such as Asana, monday.com or MS Project/Planner AI are not verified and not sourced.
