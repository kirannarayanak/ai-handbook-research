AI use cases in practice

  • Cost optimisation in the AWS console: Amazon Q Developer gives rightsizing, Savings Plan and Reserved Instance, and idle-resource recommendations and explains how each was calculated. [1]
  • Multi-step troubleshooting and mapping of relationships across AWS resources through natural-language chat. [1]
  • Generating and refining Terraform, kubectl manifests and gcloud commands in Gemini Cloud Assist, with IAM policy help and simulation in chat. [2]
  • Designing, operating, optimising and troubleshooting Azure apps in Azure Copilot, which acts within the user's permissions and requires confirmation for actions. [3]
  • Agentic infrastructure-as-code authoring with Claude Code. Its best-practice guide advises giving the agent a pass/fail check and using plan mode; running terraform plan as that check is this handbook's suggestion, not stated by the source. [4]

Capstone deliverable

For a sandbox account, produce a Terraform module using an AI assistant, run plan and a policy scan, and deliver a cost-reduction analysis built from assistant recommendations that you independently verify against billing data. Include the prompt log, a list of assistant errors found, and time saved.

Data risks and rules

Cloud credentials, account IDs, network topology, IAM policies, and logs that can contain customer data (GDPR, HIPAA, PCI DSS). Rules: least-privilege access for any assistant, since the assistants act with the user's permissions [3]; human approval before apply; no secrets in prompts; verify recommendations against billing before acting.

Adoption KPIs

Cost savings realised from AI recommendations, verified; time to draft a reviewed IaC change; proportion of AI-generated IaC passing policy checks first time; troubleshooting time for common incidents; number of assistant-caused misconfigurations.

Curriculum emphasis

Specialist tier: depth on tools matching your cloud provider. Prioritise the assistant native to your cloud (Amazon Q Developer, Azure Copilot or Gemini Code Assist), plus Claude Code for cross-cloud IaC, plus GitHub Copilot for pipeline files (not verified). Spend hours on plan review and permission scoping.

Tool-list fit

The list mixes three clouds; teach each team only its own. Amazon Q Developer's page says AWS will end support for its IDE plugins on 30 April 2027 and points to Kiro as the alternative, and Gemini Code Assist is no longer sold as a new subscription, so both need availability checks. [5][6] Gemini Cloud Assist is the relevant Google product and is not named in the handbook. [2]
