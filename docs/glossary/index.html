Reference

Glossary

Every technical term used on this site, explained in one or two plain sentences. The jargon panel on each page pulls from this list.

A

Agent also: agentic, agents
An AI that does not just answer but takes actions: runs code, opens tickets, sends messages, edits systems. Agents need an approval step for anything that cannot be undone.
AI assistant also: general assistant, chatbot
A tool you talk to in plain language (Claude, Gemini, ChatGPT, Microsoft Copilot). It drafts, summarises and answers, but it can be wrong, so you check its work.

C

Capstone also: capstone deliverable
The one real piece of work a learner produces to pass the training, with their prompts, a check of every figure and a time comparison documented.
Confidence also: high confidence, medium confidence, low confidence
How well a fact-checker could verify a page. High: two or more independent sources agree. Medium: core facts verified, details not. Low: a key page could not be opened or only one source exists.
Copilot also: Copilots
Microsoft's name for its AI assistants inside Word, Excel, Teams, Power BI, security tools and Azure. One licence covers several of them.
Credits / SCUs also: credits, Security Compute Units, consumption pricing, metered
Many AI features are not priced per user but by usage, measured in credits or compute units. Costs can rise with use and need monitoring.

D

Data residency also: residency, in-region
Where your data is stored and processed. Some tools keep EU or UK data in Europe; some process everything in the US. This matters for privacy law.

E

Enterprise plan also: enterprise tier, business tier, consumer tier
The paid company version of a tool, with admin controls, audit logs and contracts. Consumer and free versions have weaker protections; business plans sit in between.
EU AI Act also: Article 4, Digital Omnibus, Annex III
The European Union's AI law. Article 4 requires employers to support staff AI literacy (keep your training records); Annex III adds stricter duties for AI used in hiring and employment from December 2027.

G

GDPR also: personal data
The EU's data protection law. Any AI use involving information about identifiable people has to respect it.

H

Hallucination also: hallucinate, hallucinations
When an AI states something false with confidence, including invented quotes, numbers or links. The fix is to open the source before you repeat it.

I

IDE also: IDEs
Integrated development environment: the program developers write code in (VS Code, JetBrains). Coding assistants live inside it.

K

KPI also: adoption KPIs, KPIs
Key performance indicator: a number you track to see whether the training changed anything, such as hours saved per report or error rate on review.

M

MCP also: Model Context Protocol, connectors
Model Context Protocol: a standard way to connect an AI tool to other systems (files, tickets, databases). Powerful, so access should be scoped carefully.

O

Open source also: Apache 2.0, open-source
Software whose code is public and free to use. You run it yourself, so security depends on your own setup.

P

Prompt also: prompting, prompts
The instruction or question you give an AI tool. Clear prompts with context and a desired format get better results.
Prompt injection also: injection
A trick where text inside an email, web page or document secretly instructs an AI agent to do something harmful. It is why agents should not act on content you do not trust.

R

RAG also: retrieval-augmented generation, grounded
Retrieval-augmented generation: the AI looks up your documents first and answers from them, which reduces but does not remove errors.
Retention also: retained, retention period
How long a tool keeps your prompts and outputs. Enterprise plans usually let an administrator set this.

S

Semantic model also: semantic layer
A prepared, named description of a company's data that lets AI answer business questions accurately. Unprepared data gives unreliable answers.
Shadow AI also: unsanctioned AI, personal AI apps
Staff using AI tools the company has not approved, often personal accounts, which can leak confidential data.
SOC also: security operations, SIEM
Security Operations Centre: the team that watches for cyber attacks. SIEM is the software that collects their security logs.

T

Tier also: Core, Advanced, Specialist
The handbook's training depth: Core (6-10 hours per tool), Advanced (12-20), Specialist (20-40+). A department's tier sets how long to budget.
Training on your data also: model training, train on
Whether the vendor uses what you type to improve its AI model. Business and enterprise plans almost always say no by default; free consumer plans often say yes.

V

Vendor claim also: vendor-reported, vendor-stated, self-reported
A figure published by the company that sells the tool. It may be true, but no one independent has checked it.
Verified also: not verified
Verified means a researcher opened the page and read the claim on it. Not verified means it came from a search snippet or a page that would not load, so treat it with care.
