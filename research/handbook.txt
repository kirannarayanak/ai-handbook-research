 TRAINING PRINCIPLES
 Foundation (all employees): Learn one employer-approved general AI assistant (ChatGPT, Claude or Gemini), prompting,
 verification, privacy, data handling, source checking, and human review. Tools listed below are recommended options, not universal
 mandatory purchases.
 Role-based: Select 2–4 tools for practical exercises, including a general assistant and the specialist platform most relevant to the role.
 Gamma is useful primarily for presentations; Canva for design; NotebookLM for source-grounded study and synthesis.
 Proficiency: Core = 6–10 hours; Advanced = 12–20 hours; Specialist = 20–40+ hours. Assess real deliverables, safe data use, output
 accuracy and repeatable workflow.
 Important: Enterprise licensing, data residency, integrations and product features vary. Validate before adoption. Never upload
 confidential company, customer, employee, financial or legal information into unapproved tools.


 AI TOOL SELECTION QUICK GUIDE
 ChatGPT: writing, analysis, structured problem-solving, coding and workflow support.
 Claude: long-document synthesis, careful drafting, code assistance and reasoning.
 Gemini: research, multimodal work and Google Workspace workflows (where licensed).
 Gamma: rapid presentation, proposal and training-deck creation; human design review needed.
 NotebookLM: working with uploaded source materials, study guides and grounded Q&A.
 Canva Magic Studio: marketing graphics, posters, social creatives and course materials.
 Perplexity: web-supported discovery and competitive scanning with source validation.
 GitHub Copilot / Claude Code / Gemini Code Assist: coding support with secure repository controls.
